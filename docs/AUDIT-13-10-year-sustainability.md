# Audit 13 — 10-Year Sustainability Principles

Checked 2026-09-15 against `docs/planning/13-PLAYTESTING-BALANCING-AND-TELEMETRY.md` §3, as part of M13's implementation. Documentation-only per the task doc's Section 5 — no code changes are made by this audit; each principle is checked against real code as it stands today, and any gap would be opened as its own follow-up rather than fixed inline.

| Principle | Spec's claim | Verified against | Result |
|---|---|---|---|
| 1. Zero Deprecation Stack | Static single-binary Go backend (`CGO_ENABLED=0`), `scratch` Docker image | `apps/api/Dockerfile`: builder stage runs `CGO_ENABLED=0 GOOS=linux go build ...`; runtime stage is `FROM scratch`, only the static binary + CA certs + a `wget` health-check binary copied in | **Holds.** |
| 2. Offline Self-Sufficiency | PWA Service Worker caches 100% of web assets | `apps/web/vite.config.ts`'s `VitePWA({ ... })` config: `globPatterns: ['**/*.{js,css,html,png,svg,webp,json,webmanifest}']` precaches every built asset type in the bundle, plus `runtimeCaching` rules for anything fetched at runtime | **Holds**, and M18 additionally layered a `navigator.storage.persist()` request + SW-controlled status on top (`ServiceWorkerRegistry.ts`) without duplicating this precaching. |
| 3. API Resilience & Degradation | If NOAA/BLS/news RSS feeds go dark, the Go backend degrades to its internal seasonal wave + evergreen scenario vault, no crash | `apps/api/internal/pulse/economy.go` (formally re-scoped 2026-09-15 per M8's follow-up — the seasonal path is now the primary path by design, not a fallback that can fail) and `crisis_scenarios.json`'s 23-scenario evergreen vault (used whenever the AI narrative pipeline in `internal/narrative/` is offline or returns nothing) | **Holds**, with the caveat already on record from M8/M9: there is currently no *live* external fetch to degrade from at all (real RSS/NOAA/BLS ingestion is a formally deferred scope decision, not a built-then-degraded feature). If a live fetch is ever added, it must be wired through this same fallback path — not a new one. |
| 4. No Build Debt | Rolldown/Vite 8 + OXC toolchain, zero deprecated Webpack/esbuild dependencies | `cd apps/web && npm ls esbuild` → empty tree (no esbuild anywhere in the dependency graph); `package.json`'s `vite` devDependency is Vite 8 | **Holds.** |

**Conclusion:** all four principles are real and already shipped — this section of the planning doc needed an audit, not new engineering, matching M20's "already largely true, formalize it" precedent. No follow-up task opened.
